# CarpeDM EXPO Dashboard

CarpeDM EXPO 시연을 위한 조직 대화 훈련 현황 대시보드입니다. 기존 정적 HTML 시안을 Vite와 React 기반으로 전환했습니다.

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드는 다음 명령으로 확인합니다.

```bash
npm run build
npm run preview
```

## 현재 데이터 범위

- 화면 데이터는 EXPO 시연용 로컬 목 데이터입니다.
- API, 데이터베이스, 실제 사용자 계정과 연결되어 있지 않습니다.
- 리포트 내보내기는 현재 화면의 팀별 데이터를 CSV 파일로 생성합니다.
